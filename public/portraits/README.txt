Put character portraits in this folder.

File name = the character's id from src/data/characters.ts + .jpg
  e.g.  iron-man.jpg   doctor-strange.jpg   jean-grey.jpg

Square images work best (about 256x256). Faces near the top.
Missing images are fine: the game shows a colored initials badge instead.

Want .png or .webp instead? Set imageUrl on that character, e.g.
  imageUrl: "/portraits/iron-man.png"
